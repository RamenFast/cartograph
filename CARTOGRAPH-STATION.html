🛰 Cartograph

A living map of the machine's network, orbit to byte. eBPF hybrid capture, GTK/TUI fronts, a shared session daemon any agent can steer — and a native station-convention CLI. V1 shipped.

The signpost — what an agent runs

# the posture one-liner: ONE JSON envelope — capture mode, listeners, exposure badges, counts
surveyor status | jq

# every flow, one JSON object per line (auto-NDJSON when piped)
surveyor snapshot --json | jq -c 'select(.pid != 0)'

# the live watch: hello/posture/focus/flow/closed/tick events at 1 Hz
surveyor serve --json | jq -c 'select(.event=="flow" and .fresh)'

# move the live session's shared cursor — the human's window follows
surveyor ctl focus app firefox

# the whole machine-readable contract (a model with zero training learns the tool)
surveyor --schema

Binary: cartograph/zig-out/bin/surveyor. Pretty tables appear on a TTY; JSON the moment stdout is a pipe — the isatty move. GUI (cartograph-gtk) and TUI (cartograph) render the same view-model; nothing can drift. Opened with no arguments, the GUI joins (or spawns) the box's session daemon, so every window and every agent share one capture core and one cursor.

surveyor status — the situational check

Nexus's ask, answered: "what's my machine doing right now?" in one parse.

fieldmeaning
flowstotal · attributed · established · listeners
exposurelistener counts by reach — loopback · network · internet
listeners[]proto, local, port, pid, comm, exe, service, exposure, badge
# the attack surface in one line
surveyor status | jq '.listeners[] | select(.exposure != "loopback")'

# is the LLM server up? is ComfyUI-nothing squatting a port?
surveyor status | jq '.listeners[] | select(.comm=="llama-server")'

Station wiring

Before image generation, the orchestrator checks the card and this page's tool answers who's listening (llama-server :8108, bridge :8109, Hermes gateway). Risk badges are programmatic — anything unexpected talking shows up as a non-loopback listener with a name.

Docs of record: docs/AGENT-INTERFACE.md (the contract) · man page surveyor(1). docs/CLI.md is design source, not reference — many of its verbs are roadmap.
